# Японские слова на экране блокировки Nothing

Исследовательское приложение показывает японские иероглифы через существующую карточку Nothing. В словаре 253 знака: 84 уровня N5 и 169 уровня N4. Уровни можно включать независимо, слово — менять вручную или автоматически при включении экрана. Автоматическая смена работает локально в службе переднего плана с тихим уведомлением.

Доступны два оформления: слово поверх заранее сохранённого исходного фона и иллюстрация Меллстроя у Фудзи с облачком речи. Фон сгенерирован; слово и облачко остаются содержимым карточки.

**Это не самостоятельный универсальный виджет.** Приложение использует уже установленную штатную карточку и внутреннюю службу Nothing. Для другого телефона нужно самостоятельно определить идентификатор подходящей карточки и подготовить копию первого фона в файлах приложения. Автоматической первоначальной настройки нет. Работа зависит от версии системы и устройства, а также доступа к службе. Исходное содержимое карточки сохраняется перед изменением, если оно ещё не заменено этим приложением; сохранённую копию нужно сохранить для восстановления.

Версия 0.3 с ручной сменой и обоими оформлениями проверена на Nothing Phone (2a) Plus с Nothing OS 4.1 и Android 16. Версия 0.4, включая автоматическую смену и восстановление после перезагрузки, подготовлена и проверена только локально: на телефоне она ещё не испытана.

## Сборка в Windows

Нужны Android SDK с платформой Android 35 и Build Tools 35.0.0, а также JDK с `javac` и `keytool`. Укажите путь к SDK через `ANDROID_SDK_ROOT` или `ANDROID_HOME`; иначе используется стандартная папка Android SDK в профиле Windows. JDK берётся из `JAVA_HOME` или из стандартной установки Android Studio.

```powershell
& ./tools/card-probe/build.ps1
```

Результат появится в `output/`. При первой сборке создаётся отдельный ключ для отладки в `.local-signing/` со стандартным паролем `android`. Он предназначен только для разработки, хранится локально и исключён из репозитория. Ключ создаётся для каждой копии отдельно. Подпись такой сборки не совпадает с подписью другой установки: обновить уже установленное приложение с другой подписью этим пакетом нельзя. Удаление старой установки также удаляет её локальные данные и резервные копии; перед любыми действиями сначала восстановите карточку и сохраните нужные данные.

Приложение собрано в отладочном режиме и предоставляет служебный экран операций; оно не предназначено для безопасного распространения как готовый продукт.

## Проверки

```powershell
python scripts/check_kanji.py
& ./scripts/check_wake.ps1
```

Первая команда проверяет состав и чтения словаря, вторая — логику переходов состояния экрана. Эти проверки не заменяют испытания на телефоне. Устройство для них не требуется.
