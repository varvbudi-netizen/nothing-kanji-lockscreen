# Устройство приложения

`ThemeActivity` показывает настройки оформления и уровней. `CardController` последовательно выполняет ручные и автоматические операции с существующей карточкой через службу Nothing, сохраняет её исходное содержимое и проверяет результат записи. `KanjiCatalog` загружает локальные списки. Макеты карточки находятся в `tools/card-probe/res/`.

`WakeService` слушает события выключения и включения экрана; `ScreenWakeGate` определяет допустимый переход. `WakeBootReceiver` запускает восстановление службы после перезагрузки или обновления пакета при выполнении условий. Уведомление службы тихое. Это локальная логика версии 0.4, ещё не проверенная на телефоне.

`WallpaperThemes` переключает фон блокировки. Для первого оформления ожидается файл `wallpapers/plain.img` во внутреннем хранилище приложения; для второго используется сгенерированная иллюстрация из ресурсов. Подготовка файла и определение идентификатора существующей карточки не автоматизированы.

Связь со службой основана на внутреннем интерфейсе конкретной версии Nothing и может измениться. Отладочная сборка и доступный извне `ProbeActivity` предназначены для исследования, а не для готового продукта. Сохранённая карточка и исходный фон могут содержать личные данные и не должны попадать в репозиторий.
