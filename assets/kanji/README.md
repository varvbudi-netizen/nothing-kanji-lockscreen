# Иероглифы уровней N5 и N4

В `n5.json` содержатся 84 знака, в `n4.json` — 169 других знаков; уровни не пересекаются. Распределение взято из [OpenJLPT](https://github.com/evanclan/OpenJLPT), версия `0d1d3410bec90bd4098a7c72de820543cb4f707c`. Оно основано на учебных списках Джонатана Уоллера и дополнениях OpenJLPT. Это неофициальные ориентиры: организаторы современного экзамена не публикуют официальный перечень знаков.

Японские чтения воспроизведены из OpenJLPT без изменений; их словарный источник — [KANJIDIC2](https://www.edrdg.org/wiki/KANJIDIC_Project.html), Electronic Dictionary Research and Development Group (EDRDG). Точка отделяет изменяемую часть слова, дефис обозначает употребление в составе слова. Русские значения кратко переведены и отобраны по английским значениям источника; они не охватывают все значения и зависят от контекста.
